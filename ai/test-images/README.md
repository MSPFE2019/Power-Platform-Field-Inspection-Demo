# Demo test images

Place presenter-owned or royalty-free photos in this folder before the demo:

- `broken-stop-sign.jpg` - bent or knocked-down stop/traffic sign.
- `graffitied-park-bench.jpg` - park bench or fixture with visible graffiti.
- `water-pooling-sidewalk.jpg` - standing water on sidewalk or street edge.
- `vegetation-covering-sign.jpg` - vegetation blocking a road sign.
- `water-stained-ceiling-tile.jpg` - facility ceiling tile with water staining.

Do not commit photos that contain faces, license plates, private property interiors, or location metadata unless they are cleared for public demo use.
